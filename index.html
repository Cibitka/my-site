    Cibitube — нативный клиент YouTube Music

    Десктопный клиент YouTube Music на Rust без Electron с собственным графическим интерфейсом, синхронизацией через Google Drive и загрузчиком с обложками и текстами .lrc.

    Версия: v0.2.10 Звёзды: 0 Обновлён: 2026-11-20
    Архитектура: Rust (2021), GUI на egui / eframe 0.30, воспроизведение через MPV IPC, загрузка и метаданные через yt-dlp + ffmpeg, тексты песен из LRCLIB, бессерверная синхронизация через cibitube_sync_state.json в Google Drive.
    Платформы: Linux (Arch Linux / AUR, Ubuntu / Debian, Fedora); Android-клиент в разработке.
